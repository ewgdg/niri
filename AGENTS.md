# Repository Agent Instructions

## Fork Scope

- This repository is maintained as a personal fork.
- Do not create upstream issues, discussions, pull requests, or other upstream requests unless the user explicitly asks.
- Apply upstream contribution and release conventions only when preparing an upstream contribution.

## Release Metadata

- Do not invent release metadata for personal-fork changes.
- Do not add `Since` annotations, changelog entries, release versions, or similar release markers unless this fork actually publishes releases or the user explicitly requests them.
